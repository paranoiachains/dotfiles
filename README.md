# Dotfiles collection ^_^

Almost complete Linux desktop dotfiles collection.

Tried to use only well-maintained projects:

- [Neovim](https://github.com/neovim/neovim)
- [Zsh](https://github.com/zsh-users/zsh)
- [tmux](https://github.com/tmux/tmux)
- [Sway](https://github.com/swaywm/sway)
- [Waybar](https://github.com/Alexays/Waybar)
- [Ghostty](https://github.com/ghostty-org/ghostty)
- [mako](https://github.com/emersion/mako)
- [starship](https://github.com/starship/starship)
- [fzf](https://github.com/junegunn/fzf)
- [fuzzel](https://codeberg.org/dnkl/fuzzel)
- [lazygit](https://github.com/jesseduffield/lazygit)

The [tokyonight](https://github.com/folke/tokyonight.nvim) theme is used throughout the repository.

# Load/push dotfiles into environment/repo

Use `./load.sh` script:

```command
./load.sh push|pull
```
